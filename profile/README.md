# GoTreat

**Digital collaboration for medical practices.**

GoTreat builds software that makes everyday practice life easier: less paperwork, faster coordination within the team, more time for patients. Our solution complements existing practice management software instead of replacing it, and runs directly in the practice.

## What we're working on

- **GoTreat App**: A work and communication platform for practice teams, starting with dental practices
- **Website**: [gotreat.de](https://gotreat.de)

We're a young team still in the early stages. Most of our code is not public.
